# Quick
Descripción del algoritmo

QuickSort es un algoritmo de ordenamiento basado en la técnica Divide y Vencerás.

Funcionamiento:

Selecciona un pivote.

Divide el arreglo en dos subarreglos:

Elementos menores o iguales al pivote.

Elementos mayores al pivote.

Aplica recursivamente el mismo procedimiento.

Complejidad:

Mejor caso: O(n log n)

Caso promedio: O(n log n)

Peor caso: O(n²)
